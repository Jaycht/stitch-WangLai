### 问题 2：时间输入框超出界面 + 没有默认值（截图 40094）
- **现象（涛哥原话）**：
  - 「时间的输入框都除了界面了」→ **超出右边界**
  - 「里面应该默认有当前时间吧，什么都没有，用户根本不知道这是个什么输入框」
- **根因（已核实）**：
  - 宽度写死 `className="field w-[7.5rem] shrink-0"`，两处（690/920 行）
  - 大字模式下 `--f-md` 变大 → `type="time"` 原生控件**内部宽度跟着涨**，

- **明天要做的**：

  2. **默认填当前时间**（新建记录时），编辑旧记录时保留原值
  3. **加 placeholder 或 label 提示**（原生 time 控件不支持 placeholder，

  4. 时间改成**可选**：用户可以清空（清空后 `undefined`，只登记日期）
- ⚠️ **与「不强制填」原则不冲突**：默认值是"方便"，不是"强制"。
  用户可以清空。

### ★★★ 本次最大发现：全app字号一直失效（Tailwind v4 坑）
- **现象**：查历史框"字体很小"，顺手用 Playwright 量真实计算字号，发现
  **金额(f-num)、标题(f-lg)、辅助(f-xs) 全部 = 13px**，层级完全没出来。
- **根因**：Tailwind v4 把 `text-[var(--f-lg)]` 这类**无法判定类型的变量值**
  当成 **颜色** 类编译 → 生成 `color:var(--f-lg)`（14px 不是颜色 → 被丢弃），
  **根本没有 font-size**。实测产物 CSS：`font-size:var(--f-lg)` 出现 **0 次**。
- **正确做法**：加类型提示 `text-[length:var(--f-*)]` → 生成 `font-size:var(--f-*)`。
- **动作**：全局机械替换 17 文件 / 237 处（`text-[var(--f-` → `text-[length:var(--f-`）。
  重建后实测：f-num=18px、f-lg=14px、f-sm=11.5px、f-xs=10.5px ✓。
- **提交前教训**：**tsc/build 永远查不出这种问题**——它是"CSS 语义"错，编译全绿。
  必须**运行时量 computed style 才算验证**。
