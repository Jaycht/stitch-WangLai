### 问题 2：时间输入框超出界面 + 没有默认值（截图 40094）
- **现象（涛哥原话）**：
  - 「时间的输入框都除了界面了」→ **超出右边界**

- **根因（已核实）**：

- ⚠️ **与「不强制填」原则不冲突**：默认值是"方便"，不是"强制"。

### ★★★ 本次最大发现：全app字号一直失效（Tailwind v4 坑）
- **现象**：查历史框"字体很小"，顺手用 Playwright 量真实计算字号，发现
  **金额(f-num)、标题(f-lg)、辅助(f-xs) 全部 = 13px**，层级完全没出来。
- **根因**：Tailwind v4 把 `text-[var(--f-lg)]` 这类**无法判定类型的变量值**
  当成 **颜色** 类编译 → 生成 `color:var(--f-lg)`（14px 不是颜色 → 被丢弃），
  **根本没有 font-size**。实测产物 CSS：`font-size:var(--f-lg)` 出现 **0 次**。
- **正确做法**：加类型提示 `text-[length:var(--f-*)]` → 生成 `font-size:var(--f-*)`。
- **动作**：全局机械替换 17 文件 / 237 处（`text-[var(--f-` → `text-[length:var(--f-`）。
  重建后实测：f-num=18px、f-lg=14px、f-sm=11.5px、f-xs=10.5px ✓。
- **提交前教训**：**tsc/build 永远查不出这种问题**——它是"CSS 语义"错，编译全绿。
  必须**运行时量 computed style 才算验证**。

## ★★ 2026-10-09 19:45 v2.14.6：录入模型重构 + 4 个真机问题修复（大字模式原则确立）

### 涛哥 4 个真机问题（截图确认）
1. **大字模式长按多选后「删除」被挤出屏幕外**；全选后「取消全选」变长更挤
2. **删除确认弹窗按钮比例太小**（写死 h-11=44px，大字下不够大）
3. **列表排版乱**：满眼都是字、段落多、对不齐（标准模式也有）
4. **★架构级：录入模型方向搞反** —— 涛哥原话：
   > 「我越看越迷糊，收礼是对方办的，回礼又是我放办的，如果是别人的婚礼我给了份子钱，那我到底应该记在哪里？」

### #4 的根因（我参考参考错了）
参考 App 的核心不是"多一个字段"，而是**换了一个记录维度**。
我原来的「收礼（对方办的）/ 回礼（我方办的）」**把「钱的方向」和「谁办事」混成了一锅**：
- 别人婚礼我给份子钱 → 钱是**我给出**，但标签暗示"我方办事" → 越记越迷糊

### 方案（涛哥拍板）
- **悬浮方向菜单**：点加号 → 就近弹「对方办事 / 我方办事」→ 选完再进录入表单
  （涛哥否掉了我的并排双 Tab 方案：「大字模式下屏幕又显得很拥挤」）
- 方向决定钱的方向，用户**不需要判断**：对方办事=我随礼付出（落 `returned`）；我方办事=我收到的礼金（落 `received`）
- **回礼改为「另一条记录」**：原表单「回礼」整组移除；老数据的回礼完整保留

### 🔴 本轮新增教训（已记入跨项目教训库 16.13）
1. **`env -u http_proxy ... cmd` 在 Git Bash 下会吞掉子进程全部 stdout**
   —— 表现为「零输出 + exit 0」，极易误判成脚本没问题。
   排查耗时很久。**正解：在 Python 内部 `os.environ.pop()`**，或写进脚本，
   不要用 `env -u` 包装。
2. **`pkill -f "vite preview"` 会把自己也杀掉** —— 因为 shell 自己的命令行里
   含同样字符串。用 TaskStop 或把 pkill 与启动拆成两条命令。
3. **history 路由的 SPA 不能用 `python -m http.server` 验证**：
   点「我的」后地址栏变 `/me`，reload 直接 404 白屏 →
   已新建 `_ui_compare/serve.py`（多线程 + SPA fallback），验证统一用它。
