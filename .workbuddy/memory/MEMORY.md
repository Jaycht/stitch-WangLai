# 往来礼记 · 项目长期约定

## ★ 大字模式（关怀模式）唯一原则 —— 最高优先级

> 涛哥原话（2026-10-09）：
> 「因为我们是做给年纪大的人用的，所以说我们大字模式（繁体中文）里面的原则就是，
> **在不破坏基本录入功能和备份恢复功能的前提下，越简洁越好**」

### 落到实处的判断标准
- ✅ **要保留**：录入（姓名+金额+备注）、备份与恢复、列表（姓名+金额）
- ❌ **要砍掉**：一切"锦上添花"的字段与展示
  - 事由（整个 FieldGroup 隐藏）
  - 渠道 / 地点 / 礼物 / 日期时刻 / 时刻（隐藏或并入备注框）
  - 列表里除姓名金额外的一切（事由徽标、日期、方向词、回礼详情）
  - 记录页的人员/全选入口、合计卡、筛选、搜索、姓名快捷 chip
  - 设置页只留「备份与恢复 / 大字模式切换 / 关于」
  - 功能页去掉「待办事项 / 渠道分布 / 事由分布 / 往来最多」

### 已达成的效果（v2.14.6 实测）
- 记一笔录入字段：**8 个 → 3 个**（对方姓名 / 金额 / 备注）
- 列表每行文字：**3 行 → 1 行**（只有姓名 + 金额）

## ★ 录入模型：方向优先（v2.14.6 重构）

### 概念（这是本应用最容易搞错的地方）
| 方向 | 含义 | 钱记在哪 |
|---|---|---|
| **对方办事** | 别人办席，我随礼**付出** | `returned` |
| **我方办事** | 我办席，收对方的礼 | `received` |

### 交互
- 点「＋」→ **就近弹悬浮菜单**（对方办事 / 我方办事）→ 选完再进表单
  - ★ 不用并排双 Tab：大字模式下并排会挤（涛哥否掉了这个方案）
- 方向决定钱的方向，**用户不需要判断「钱该怎么记」**
- **回礼 = 另一条记录**（再点一次加号选另一个方向），不再在同一表单里
- 编辑旧记录按内容自动反推方向，不弹菜单

### 老数据归类规则（涛哥拍板）
- 付出的钱（`returned`）→ 对方办事
- 收到的钱（`received`）→ 我方办事
- 同一人两边都有 → **拆成两条记录**，都进往来记录
- **数据结构零改动**，所以历史记录零迁移、统计口径不变

## 数据结构要点
- 存储键：`localStorage['wanglai.db.v1']`，`schemaVersion = 3`
- `GiftRecord.received: Side`（我收到的钱）、`returned?: Side`（我给出去的钱）
- 备份：JSON 全量导出/恢复，覆盖/合并两种模式；**这是大字模式必须保住的底线功能**
- `remindAt`/`reminded` 等提醒字段已随 v2.14.0「不提供提醒服务」废弃

## 验证铁律（涛哥定的，反复踩坑）
1. **`npm run build` 只是 `vite build`，不含类型检查** → 必须单独跑 `npm run lint`(tsc --noEmit)
2. **编译绿 ≠ 功能对**：必须用真实浏览器（Playwright + 本机 chromium）量运行时行为
3. **要断言「输入→输出」，不是断言「代码存在」**
4. **看截图**：flex 里不可换行的 chip 挤进文字流这类 bug，断言测不出来，只有截图能抓
   （v2.14.6 就踩了：文字被压成竖排、金额被压住，断言全绿但真机是坏的）
5. `vite preview` 起服务时**要清掉代理环境变量**，否则 localhost 请求会被劫持
   ```bash
   env -u http_proxy -u https_proxy -u HTTP_PROXY -u HTTPS_PROXY npm run preview
   ```
6. git 推送用 `https_proxy=http://127.0.0.1:7897`（环境变量里的透明代理是失效的）

## Tailwind v4 踩坑
- `text-[var(--f-*)]` 会被当成**颜色**类 → font-size 从未生成 → 全app 文字挤在 13px
- 正确写法：**`text-[length:var(--f-*)]`**（237 处，已全局替换）

## UI 硬需求
- **尺寸一律不写死 px**，用 `flex-1` 等自适应 + `var(--h-btn)` 等令牌
  （字号放大时容器高度会跟着长高，写死 px 必然装不下字）
- 横排按钮**绝不能**依赖 `shrink-0` 硬撑，会被挤出屏幕 → 用 `flex-1 min-w-0` 均分
- CSS 变体类不能只写颜色，必须自带 `display/align-items/height/font-size/padding`
